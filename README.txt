FIVEBUCKS HOMEPAGE STARTER

Files:
- index.html: homepage structure
- styles.css: responsive modern-premium styling
- script.js: product catalogue, search, category filters, add-to-cart and demo cart

PREVIEW LOCALLY:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.

DEPLOY FREE ON VERCEL:
1. Create a GitHub repository and upload these three files to the repository root.
2. Sign in to Vercel with GitHub and choose Add New > Project.
3. Import the repository. For this static site, no build command is required; set the output directory to ./ (or leave the static default if detected).
4. Deploy. Vercel will provide a free *.vercel.app address.

IMPORTANT BEFORE TAKING REAL ORDERS:
- The products and product images are illustrative demo content. Replace them with real products, accurate specifications, supplier costs and rights-cleared images.
- The cart is front-end demo functionality only. Checkout intentionally does not collect payment.
- Connect a legitimate payment provider, backend order database, fulfilment workflow, shipping/tax calculation, customer support, privacy/terms/returns policies and genuine tracking before launch.
- Do not advertise free shipping unless the shipping cost is included in your pricing and the promise can be fulfilled.
- The newsletter form is a demo and does not store email addresses.
